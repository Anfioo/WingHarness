# Provider icon sources

The Mail account rail and account form use these bundled marks so provider
logos work offline.

- `microsoft-outlook.png`: official Outlook favicon from `outlook.live.com`.
- `netease-mail.png`: official NetEase Mail favicon from `mail.163.com`.
- `gmail.svg`, `qq.svg`, `alibabacloud.svg`, `icloud.svg`, `maildotru.svg`,
  `sinaweibo.svg`: from [Simple Icons](https://simpleicons.org/), which is
  released under CC0-1.0. The brand colour is applied at build time in
  `src/components/one-mail/provider-icon.tsx`.

The marks are trademarks of their owners and are used only to identify the
mail service an account belongs to. OneMail carries the same set under the same
terms; see `src-tauri/one-mail-core/UPSTREAM.md`.
