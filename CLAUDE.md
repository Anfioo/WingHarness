# WingHarness

A Tauri v2 desktop template. The shell, the native plumbing and one worked
example of each platform feature are done; what the app is *for* is yours to add.

## Architecture

- **Frontend**: React 19 + TypeScript + Vite 7 + Tailwind CSS v4 + shadcn/ui
- **Backend**: Tauri v2 (Rust)
- **Build**: pnpm + Vite + Cargo

## Development

### Prerequisites

- Node.js >= 18
- pnpm >= 9
- Rust >= 1.70

### Commands

```bash
pnpm install        # Install dependencies
pnpm tauri dev      # Dev server (:11420) + the app
pnpm tauri build    # Production bundle
pnpm check          # prettier --check + eslint + tsc + vite build
pnpm format         # Format code
```

## Coding Standards

### TypeScript/React

- TypeScript strict mode
- Function components with Hooks
- Path alias: `@/` maps to `src/`
- Format with Prettier; do not reformat a file you did not otherwise change
- **Comments, console logs and error strings MUST be in English only**

### Rust

- Follow Rust naming conventions
- `#[tauri::command]` for Tauri commands
- **Comments, console logs and error strings MUST be in English only**

### Styling

- Tailwind CSS v4
- shadcn/ui component system
- CSS variables for theming (light/dark mode)

### Code Quality Rules

1. **Language**: all comments, console logs and error messages in English
2. **Cleanliness**: remove code you replace — no commented-out leftovers
3. **Simplicity**: KISS; no abstraction before the second caller

## Key Conventions

### Adding a page or a window

A page needs an entry in `pageMap`, a row in `appRoutes`, and its strings in both
locale files. A window additionally needs `standalonePaths`, a window record in
`src-tauri/tauri.conf.json`, and its label in `capabilities/default.json`.
[src/CLAUDE.md](./src/CLAUDE.md) has the step-by-step.

### Adding a Tauri command

A command must be named in four hand-maintained lists, not one — `invoke.rs`,
`build.rs`, `capabilities/default.json` and `permissions/autogenerated/*.toml`.
`build.rs` fails the build when the first two disagree.
[src-tauri/CLAUDE.md](./src-tauri/CLAUDE.md) has the details.

### Persisted data

Anything the app writes at runtime goes under `config::dir()` (the configurable
data directory). Never the config directory root, never `localStorage`.

### Internationalization

- English and Chinese must stay key-for-key identical; both live in
  `src/i18n/locales/`
- No key without a caller — a string nobody translates is a string to delete
- Never hardcode user-facing copy in a component; see [docs/I18N.md](./docs/I18N.md)

### Documentation

When adding a feature that deserves a guide, write both language versions:
`docs/FEATURE.md` and `docs/FEATURE.zh-CN.md`, and add them to the table in
[README.md](./README.md) and [README.zh-CN.md](./README.zh-CN.md).
