# 下载

**下载**页面（`/moin`）是 WingHarness 的 HTTP/HTTPS 下载管理器。入口位于侧边栏
「其他」分组，只有一个视图：下载列表，带状态筛选、搜索与排序。分类通过筛选行
的分类菜单管理。下载相关的设置位于应用的设置窗口「下载」分区。下载引擎内嵌在
Tauri 进程中，不需要安装或管理独立的下载守护进程。

本移植只覆盖 HTTP/HTTPS 直链下载，不包含 BitTorrent、媒体站点抓取、
`moin://` deep link、旧 moin 数据迁移和应用内 aria2c 安装。

## 功能概览

| 区域       | 行为                                                                                                                |
| ---------- | ------------------------------------------------------------------------------------------------------------------- |
| 下载       | 添加 URL，可选文件名、分类和请求头；查看状态、进度、速度、ETA、引擎与错误；分段下载时每行下方按连接显示各自进度条；支持虚拟滚动、搜索、筛选和最多三级排序。 |
| 任务操作   | 单条或批量暂停、继续、重试、取消、删除记录；还可显示已完成文件、复制链接、移动到其他分类。                        |
| 分类       | 通过筛选行的分类菜单：「新建分类」直接建一个，「管理分类」打开卡片网格——新建、编辑、删除、拖拽排序，可配置颜色、图标、来源、优先级、保存目录与暂存目录。 |
| 设置       | 位于应用设置窗口的「下载」分区：队列、连接数、分片大小、超时、半成品可见性、通知、下载引擎与浏览器集成。 |
| 浏览器捕获 | 配套扩展通过需要鉴权的本机回环 RPC 投递链接，见 [MOIN_EXTENSION.zh-CN.md](./MOIN_EXTENSION.zh-CN.md)。              |

## 下载流程

1. 添加 `http://` 或 `https://` 链接。页面可根据 URL 与可选文件名建议分类。
   Cookie、Referer、User-Agent 等请求头为可选项，会保留给重试与续传使用。
2. 引擎选择首选的可用后端并探测服务器。支持 `Range` 时使用多连接分段，
   否则退回单流。新建分段下载会在 `.part` 旁写入 `.part.meta` 计划。
3. 完成前数据写入 `<目标路径>.part`。暂停、取消、重试和应用退出都会保留
   半成品，供后续续传。应用重启会把未完成的连接中、下载中、移动中任务
   降为已暂停，不会自动续传。
4. 分类配置暂存目录时，半成品位于暂存目录，完成后搬到保存目录。跨卷搬移
   使用复制加删除，并上报「移动中」进度。
5. 完成后去掉半成品后缀、更新 SQLite 记录，并可弹出系统通知。关闭主窗口
   只会隐藏到托盘，下载继续；从托盘退出会结束应用，并保留 `.part` 供下次
   运行使用。

列表只有三个状态分类：**未完成**（排队中、连接中、下载中、移动中、已暂停、已取消）、
**已完成** 与 **失败**。删除记录会同时从列表和数据库移除，磁盘上的成品与半成品文件
保留；唯一会连文件一起删除的是运行时安装器，它通过 `delete_files` 清掉临时压缩包。

## 分类与触发规则

分类可接受手动链接、浏览器捕获或两种来源。来源列表为空表示接受任意来源。
同一分类中的每条触发规则都必须通过，命中的分类按数值 `order` 从小到大
取第一个。触发规则为空时，该分类会成为通用兜底分类。

| 触发器     | 语义                                                     |
| ---------- | -------------------------------------------------------- |
| 扩展名     | 扩展名匹配不区分大小写，可省略前导点。                   |
| 大小       | 以字节表示的可选包含边界上下限；总大小未知的任务不匹配。 |
| URL 模式   | 对 URL 做不区分大小写的 glob 匹配。                      |
| 文件名模式 | 对文件名做不区分大小写的 glob 匹配。                     |

glob 支持 `*` 与 `?`，不含通配符时退化为子串匹配。分类可从「全部」筛选中
隐藏其任务，也可分别设置保存目录与暂存目录。删除分类只会清除任务的分类
标签，不搬移或删除文件。把任务移到另一分类时，如果目录发生变化，会同时
搬移半成品或成品。

全新数据目录会播种 Documents、Videos、Archives 三个分类。落盘的英文名称
保持不变，界面按三个已知 id 本地化显示。BitTorrent 时代的未知分类字段在
JSON 读写时原样保留，但在本移植中没有界面或运行时作用。

## 内置引擎与 aria2

默认 `embedded` 引擎使用 reqwest，支持单流与多连接下载。可选 `aria2` 引擎
使用本机 `aria2c` 及其回环 JSON-RPC 接口。WingHarness 按以下顺序探测：

1. 设置中显式选择的路径；
2. `WINGHARNESS_ARIA2` 环境变量；
3. `PATH`。

应用不会下载 aria2c。选择 aria2 表示首选引擎而非硬性要求：可执行文件缺失
或不可用时，新任务会回退到内置引擎，设置窗口的「下载」分区同时展示探测状态。aria2 进程
按需启动，并随应用退出关闭。

## 设置

以下各项均位于应用设置窗口的「下载」分区，修改后立即生效，没有保存按钮。

| 设置                 | 作用                                                                |
| -------------------- | ------------------------------------------------------------------- |
| 默认下载目录         | 未分类任务使用；留空表示系统下载目录。                              |
| 同时下载数           | 最大运行任务数；`0` 表示不限。                                      |
| 连接数／最小分片大小 | 控制内置引擎何时以及如何分段；传给 aria2 的值会钳制到其可接受范围。 |
| 连接／停滞超时       | 建连上限与无数据上限；停滞超时为 `0` 时关闭停滞检测。               |
| 隐藏未完成的分片     | 在支持的平台上给 `.part` 设置隐藏属性。                             |
| 添加后先暂停         | 新任务以已暂停状态等待，不立即开始。                                |
| 进度刷新频率         | 合批进度事件；实际间隔钳制在 100–5000 ms。                          |
| 下载完成通知         | 任务完成时发送系统通知。                                            |
| 浏览器集成开关／端口 | 应用启动时生效，修改后需重启；默认端口为 `47653`。                  |
| 访问令牌             | 每次 RPC 请求都会读取，重新生成后立即生效；扩展中也要同步更新。     |
| 代理                 | 遵循设置 → **代理**的 `不使用 / 系统 / 自定义`；修改后会重建下载客户端。已在运行的 aria2 进程要等重新拉起才生效。 |

其他队列、网络、引擎与通知设置对后续工作生效，无需重启应用。

## 浏览器集成

RPC 只绑定 `127.0.0.1`。`GET /ping` 免鉴权并返回应用名与版本；
`POST /add` 需要 `Authorization: Bearer <token>`，且只接受 HTTP/HTTPS
链接。空令牌或错误令牌一律拒绝。监听器在应用初始化时启动一次；端口冲突
只记录日志，不会导致应用崩溃。

扩展只以源码提供，不随 NSIS 安装包分发，也不能通过 deep link 拉起
WingHarness。配对、浏览器加载、权限与隐私说明见
[MOIN_EXTENSION.zh-CN.md](./MOIN_EXTENSION.zh-CN.md)。

## 数据目录与敏感信息

本功能的全部状态都位于可配置的应用数据目录下：

```
<data dir>/moin/
├── downloads.db                 # Task records and request headers
├── settings.json                # Queue, engine and RPC settings, including rpc_token
├── categories.json              # Category definitions and preserved legacy fields
└── aria2/                       # aria2 session.txt and per-task session notes
```

半成品与 `.part.meta` 计划位于目标文件旁或分类的暂存目录，不在上述状态目录。
JSON 通过保留完整文件名的临时文件、刷新和 rename 原子写入。无法解析的 JSON
会先改名为 `<name>.bak-<unix 秒>`，再使用默认值。

**整个数据目录都应视为敏感数据。** `settings.json` 明文保存 RPC 令牌，
`downloads.db` 可能包含 Cookie、Authorization、Referer 等认证下载所需请求头。
能读取这些值的人，在浏览器集成运行期间即可调用本机 `/add`，还可能在其他地方
重用捕获的凭据。不要提交、公开同步或随意分享此目录。扩展也会把令牌保存在
浏览器自己的本地扩展存储中。

## 命令与事件

全部命令以 `moin_` 为前缀，并登记在 `invoke.rs`、`build.rs`、
`capabilities/default.json` 与 `permissions/autogenerated/` 中。

| 分组 | 命令                                                                                                                                                                                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 任务 | `moin_list_downloads`、`moin_add_download`、`moin_pause_download`、`moin_resume_download`、`moin_cancel_download`、`moin_delete_download`、`moin_delete_downloads`、`moin_retry_download` |
| 设置 | `moin_get_settings`、`moin_set_settings`、`moin_patch_settings`                                                                                                                                                                                                    |
| 引擎 | `moin_list_backends`、`moin_tool_status`、`moin_set_tool_path`                                                                                                                                                                                                     |
| RPC  | `moin_rpc_status`、`moin_regenerate_rpc_token`                                                                                                                                                                                                                     |
| 分类 | `moin_list_categories`、`moin_suggest_category`、`moin_create_category`、`moin_update_category`、`moin_delete_category`、`moin_reorder_categories`、`moin_move_to_category`                                                                                        |
| 路径 | `moin_default_download_dir`、`moin_category_folder`                                                                                                                                                                                                                |
| 应用 | `moin_app_info`                                                                                                                                                                                                                                                    |

后端事件为 `moin:task-added`、`moin:task-updated`、`moin:task-removed`、
`moin:task-progress`、`moin:task-completed`、`moin:settings-changed` 与
`moin:categories-changed`。进度载荷始终为批次。分段下载的载荷带有
`segments`（每条连接一个 `{ start, end, position }`），单流下载为空列表。
内置引擎上报真实位置；aria2 只提供汇总的 `completedLength`，其分段按连接数
均分，仅用于展示。错误使用
`{ code, message, detail? }`；界面按稳定错误码本地化，英文 message 作为兜底。

## 开发检查

在仓库根目录运行本功能门禁：

```bash
cargo check --manifest-path src-tauri/Cargo.toml -p moin-core
cargo test --manifest-path src-tauri/Cargo.toml -p moin-core
pnpm build
pnpm exec eslint src/pages/moin src/components/moin src/hooks/use-moin-tasks.ts src/hooks/use-moin-settings.ts src/hooks/use-moin-categories.ts src/commands/services/moin src/lib/moin
pnpm exec prettier --check src/pages/moin src/components/moin src/lib/moin src/commands/services/moin src/i18n/locales/moin
```

需要真实 aria2c 的测试标有 `#[ignore]`。回环 RPC socket 测试默认也被忽略，
可用完整测试名配合 `--ignored` 显式选择运行。

## 故障排查

| 现象               | 可能原因与处理                                                              |
| ------------------ | --------------------------------------------------------------------------- |
| URL 很快变为失败   | 检查 URL、HTTP 状态码和请求头。404 会使任务失败，需要修正链接或任务后重试。 |
| 任务在停滞之后失败 | 停滞超时内没有收到数据，或连接中断。任务记为失败，`.part` 会保留，恢复网络后重试。 |
| 重启后任务为已暂停 | 这是有意设计的崩溃恢复行为。已下载字节和半成品保留，手动继续即可。          |
| aria2 不可用       | 安装或选择可运行的 `aria2c`，再重新探测。首选引擎不可用时会回退内置引擎。   |
| RPC 显示未监听     | 启用浏览器集成，检查端口冲突；修改开关或端口后重启应用。                    |
| 扩展返回 401       | 从「设置 → 浏览器集成」复制当前令牌；重新生成后旧令牌立即失效。             |
| 进度事件过密或过慢 | 调整进度刷新频率，实际值会钳制在 100–5000 ms。                              |
| 存在孤立的 `.part` | 没有任务记录的文件不会被自动删除。检查目标目录，只清理确认不再需要的文件。  |
