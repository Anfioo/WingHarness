# Screenshots

Captures of the running application, kept out of the feature guides so the
guides stay text-only and the images can be regenerated without touching them.

The old captures were inherited from the previous project and have been
removed; `placeholder.svg` stands in until the pages are ready to be captured
again. Replace it with real images when the UI is final.

## Naming

| Path | What it shows |
|------|---------------|
| `app.png` | The main window |
| `settings.png` | The settings window |
| `about.png` | The about window |
| `pages/<route>.png` | One page, named after its id in `src/lib/app-routes.ts` |

Use PNG at the window's actual size, without a drop shadow. Keep the files here
rather than under `docs/features/`, and reference them from the guides with a
relative link once they exist.

`placeholder.svg` is a stand-in and is not a capture of the app.
